Help & support

Get started

Use Transactions to record income or an expense. The Home tab shows a monthly summary and category spending bars. Budgets sets monthly category limits; Goals tracks savings; Bills lists due dates.

Repeating payments

In Transactions, create a repeating income or expense schedule. When the app opens, due entries are posted. They do not run in the background while the app is closed.

Back up and restore

Open Export to save transactions as CSV or your complete data as a JSON backup. Restoring a backup replaces existing local records, so save a backup first.

How do I install the app?

This is currently an early-access Android app. See GitHub Actions for successful test builds. It is not yet available on Google Play.

Contact

Report a bug through GitHub Issues. The developer will supply an official support email before Play Store release.
