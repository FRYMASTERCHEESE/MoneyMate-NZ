MoneyMate NZ privacy policy

Updated 12 October 2026 — cloud sync testing release

Financial records and cloud sync

MoneyMate NZ helps you track your own income, expenses, budgets, bills, goals and repeating entries. It does not access bank accounts or send money. Records are stored locally in Android's private SQLite database or your web browser's IndexedDB. An email account alone does not automatically upload existing local records.

Signed-in users can explicitly opt into cloud sync. If enabled, a versioned JSON copy of the current account's financial records is sent via HTTPS and stored in the MoneyMate NZ Supabase database in Sydney, Australia. This is not end-to-end encryption: the hosting provider processes financial records to store and serve them. Account-specific Row Level Security restricts ordinary signed-in users to their own records. Cloud copies are protected by version checks; if devices diverge, the app keeps local records rather than silently overwriting the online copy. Users must resolve conflicts and should keep independent JSON backups.

The signed-in account is identified by a stable Supabase user ID, not just the typed email string. Google sign-in, once configured and independently tested, must use the same verified Supabase identity to reach the same records. Accounts with different identity IDs are separate and are not silently merged. Existing files on an older phone or laptop do not automatically belong to a new account.

Account and authentication processing

Supabase processes email address, password hashes, account identifiers, sessions, IP addresses and security events for optional registration, verification, sign-in, password reset, account recovery and deletion. The Android app encrypts session tokens with Android Keystore. The website keeps its session in the active browser tab's memory and signs out when refreshed or closed. Google OAuth and production email delivery are not confirmed for the testing release.

Supabase's authentication and database services are hosted in the Oceania (Sydney) region. Email and advertising providers may process data elsewhere. See Supabase privacy information. Production SMTP provider identity and retention will be disclosed once configured.

Website and advertising

GitHub Pages hosts the website and public visual settings used by the Android app; normal hosting requests reveal network information such as IP address. The website does not currently show ads. The Android testing app includes Google AdMob sample advertisements with Google's consent tools. Production advertising may process device identifiers, IP addresses and ad interactions; see Google's privacy policy. We will update these disclosures before production advertising.

Retention and deletion

Local records remain until deleted or replaced, until your browser clears site data, or until Android app storage is cleared or uninstalled. Browser data may be lost when site data is cleared, so save external backups. Signing out hides signed-in financial records, but does not delete them on that device. If secure cloud sync was enabled, deleting your Supabase account also deletes the account's hosted financial snapshot via database cascade.

Use the account deletion page or the Android Account screen. Deletion requires current password and verification in the present email/password version. It cannot remove local copies on devices that are offline or signed out. Clear each device's app/browser data and exported CSV/JSON files separately. Third-party services may retain limited security logs and disaster recovery copies for their required retention periods; immediate erasure of those copies cannot be guaranteed.

Support and safety

This tool is not financial advice, not a bank, and is not directed at children. Do not post financial records, passwords or verification codes in public GitHub Issues. A monitored private support email and final processing details are required before Google Play release.
