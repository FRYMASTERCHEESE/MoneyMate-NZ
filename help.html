Help with MoneyMate NZ

Use on a laptop or Android

Open MoneyMate NZ on Windows, macOS, Linux, Android or iPhone using a modern browser. The website offers the same core budgeting sections as the Android test app: Home, Transactions, Budgets, Savings goals, Bills, Export & backup and Account. Your web records are saved in this browser, so no installation is needed. The Android test APK is available from GitHub Actions.

Transactions and monthly budgets

Use the buttons under Home or Transactions to record income or expenses. Search transactions by date, category, type or note. Set monthly category budgets; the progress bars show spending for the selected month.

Bills, savings and recurring entries

Create goals and add savings contributions. Add bills with due dates; overdue bills are highlighted. Recording a bill as paid adds a Bills expense and removes the bill. No actual banking transaction occurs. Recurring entries are posted when you open the app or site, not while it is closed.

Sign up and sign in

Use Account for optional Supabase email/password access. Confirm email using the code sent by the configured provider, if available. Password reset is supported by email code. Accounts do not automatically synchronize financial records between Android and web.

Move data between devices

Choose Export & backup → Save full JSON backup, then securely move the file to the other device and select Restore. Restoring replaces that profile's existing financial records, so make another backup first. Never upload financial exports to public GitHub Issues.

Privacy and support

Read our privacy policy and account-deletion page. For public bug reports without personal data, use GitHub Issues. A dedicated private support email will be published before the Google Play release.
