MoneyMate NZ privacy policy

Updated 14 October 2026

Financial information

MoneyMate NZ helps users manually manage income, expenses, budgets, savings goals, bills and recurring entries. It does not connect to a bank or move money. The Android app stores financial records in app-private SQLite databases. The web app stores financial records in browser IndexedDB on the computer or phone you use. Financial records are kept on this device unless the signed-in user explicitly enables Supabase cloud sync; this choice also applies to transactions they import from CSV.

Android and web financial records can sync automatically after the user enables optional cloud sync on both devices. Each signed-in account uses a separate local profile based on its Supabase user ID. Guest records remain separate. You can manually download and restore compatible JSON backups to transfer records between devices. Backups and CSV exports can contain sensitive personal financial data; keep them somewhere secure.

Google sign-in

If you choose Google sign-in, Google's authentication service confirms your identity and shares necessary account information, such as your verified email address and basic profile details, with MoneyMate NZ's authentication provider. Google does not automatically receive your local budgets or transactions through signing in. Accounts are identified by user IDs rather than email strings. Users who register solely with Google may need password recovery before using the password-confirmed account deletion flow.

Sign-up and account data

Supabase processes account email addresses, hashed passwords, identifiers, session data, IP addresses and security events to deliver email/password registration, email confirmation, sign-in, password recovery and deletion. Supabase is hosted in Sydney, Australia for this MoneyMate NZ project. Session tokens in the Android app are encrypted using Android Keystore. On the website, a renewable login session is saved in browser-private IndexedDB so your account can stay signed in after refreshing or reopening. Browser storage is not encrypted at rest by MoneyMate NZ: only sign in on devices you trust, sign out when sharing a device, and avoid clearing browser site data if you need locally saved financial records. The saved login remains separate from your private financial records. Financial records remain in browser storage and are shown only when the respective local profile is open. We do not claim that local browser storage is encrypted at rest.

Account email delivery depends on the authentication provider's configured SMTP service, which is still undergoing release testing. Read Supabase's privacy policy. A final provider-specific disclosure will be added before public release.

Website hosting and connectivity

The website runs on GitHub Pages, which receives normal web hosting requests and may collect IP addresses and browser diagnostics. The Android app may retrieve public design settings from GitHub Pages. These requests are separate from the local financial database.

Optional account syncing

If you enable cloud sync, the signed-in profile’s transactions, budgets, savings goals, bills and repeating entries are saved to MoneyMate NZ’s Supabase project in Sydney, Australia. Your other signed-in devices may download those records. Guests and accounts without consent keep financial records locally. Conflicting edits made on separate offline devices are never silently merged or overwritten. Keep separate JSON backups, especially before uninstalling the app or clearing browser storage.

Historical points data

MoneyMate Points is retired from the current website and Android app. Past daily claim dates, account IDs and point totals may remain in the Australian-hosted account database while retention and deletion are reviewed. These historical records are not financial balances and cannot be redeemed or transferred. The current app no longer offers points claims. Account deletion includes associated account data as described below.

Free NZD bank statement CSV/PDF imports and future bank connections

MoneyMate NZ can read user-selected NZD bank statement CSV and supported PDF files locally, suggest transaction categories and add approved rows to the current financial profile. PDF imports require a full transaction review because text extraction and on-device OCR can misread amounts. On the website, a pinned open-source PDF.js library is fetched from the Cloudflare cdnjs service on demand; this sends ordinary library-download requests but the selected PDF file is not uploaded to that service. The Android PDF reader uses a bundled on-device text recognition model. No direct bank login or API is used, and the selected bank file is not uploaded on its own. If optional cloud sync is enabled, imported NZD transactions join the same private account snapshot uploaded to Supabase. Australian-dollar CSV and PDF files are not supported by NZD budgets. Statement imports use the account nickname, date, category, note, type and amount to recognise previously imported rows; indistinguishable repeated transactions might not always be distinguishable. Automatic bank connections are not active. Future NZ and Australian transaction imports will require an approved financial-data provider and explicit user consent. MoneyMate NZ currently collects no bank passwords or open-banking tokens. This policy will be updated before bank connectivity launches to cover provider identity, access scope, retention and withdrawal of consent.

Administrator access

A designated MoneyMate NZ administrator can view aggregate account statistics, such as total sign-ups, confirmed accounts, Google authentication usage and the number of cloud-saved account profiles. Administrator access is restricted by server-side account permissions, not by a publicly displayed email address. The admin dashboard does not provide access to individual budgets, transaction amounts, passwords or financial exports.

Advertising

The Android app integrates Google AdMob and Google's consent tools. Development builds use Google's sample ad IDs; signed Play builds use the developer's configured AdMob app and banner identifiers. Ads are requested only when the consent SDK permits them. Google may process advertising identifiers, IP addresses, ad interactions and device diagnostics according to Google's privacy policy. The web budget tracker does not currently display advertisements; if web ads are introduced, this policy and the required notices will be updated.

Storage, deletion and retention

On Android, records remain until you delete them, clear app storage, or uninstall. In browsers, local records remain until you erase that profile or clear the browser's site data. Browser settings, private mode or device policies may remove them earlier: keep backups. Signing out hides an account's local financial records without deleting them; guests can still view the guest profile on the same device.

You can request permanent Supabase account deletion in the Android app or using the account-deletion page. The deletion service verifies identity and current password. The web budget tracker also removes the locally stored records for the active account after successful deletion on that browser. Deleting an account from one device cannot erase offline copies on other devices; clear the app or website data and any downloaded backups separately. Supabase, mail and advertising providers may retain some logs and backups under applicable retention schedules.

Contact, children and updates

This is a personal finance tracking tool, not financial advice. It is not directed at children. Do not post financial information, identification, passwords or verification codes in public GitHub Issues. A private support email and final third-party processing details must be added before a public Google Play release. We may update this policy as the app's services change.
